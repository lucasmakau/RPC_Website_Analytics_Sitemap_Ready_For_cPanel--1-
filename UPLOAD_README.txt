ROCK PRIESTHOOD CHURCH — WEBSITE UPLOAD PACKAGE
Domain: www.rockpriesthoodchurch.org

UPLOAD
1. Extract this ZIP on your computer.
2. Open the extracted folder and upload the CONTENTS of this folder to your hosting document root (usually public_html), not the enclosing ZIP or folder.
3. Keep the assets/ folder and every subfolder intact.
4. If the host asks whether to overwrite existing files, back up the old site first, then overwrite the old files.
5. Visit https://www.rockpriesthoodchurch.org and https://rockpriesthoodchurch.org; configure the preferred domain/redirect and SSL in your hosting panel.
6. Clear hosting/CDN cache if applicable and hard-refresh the browser (Ctrl+F5).

CONTACT FORM — REQUIRED LIVE ACTIVATION CHECK
The contact form sends through FormSubmit to rockpriesthoodchurch@gmail.com and requests a copy to info@rockpriesthoodchurch.org using FormSubmit’s _cc field. FormSubmit may require the recipient to approve/activate the address the first time it is used. After upload:
1. Open the Contact page on the live domain.
2. Submit a real test message using an email address you can access.
3. Check rockpriesthoodchurch@gmail.com and info@rockpriesthoodchurch.org, including Spam/Junk, for FormSubmit activation/confirmation messages and follow its instructions if requested.
4. Submit another test and confirm the actual message arrives. Do not consider form delivery verified until the email arrives.
5. If delivery does not work, check the FormSubmit recipient activation and use the visible email/phone links as fallback. The website cannot activate the mailbox on your behalf.

IMPORTANT LIMITATIONS TO ADDRESS AFTER LAUNCH
- The Events admin page currently stores event data in the browser's localStorage. Events created there are not published to every visitor and may be visible only in that browser. It is a client-side prototype, not a shared CMS. Do not rely on it for public event publishing until connected to a secure server-side/CMS service.
- The Events password is present in client-side JavaScript and therefore is not secure. Do not use it to protect confidential information. Remove/restrict admin.html or replace it with a server-authenticated CMS before relying on event administration.
- The website package is static HTML/CSS/JavaScript. No server-side form processor is included; the contact form relies on the external FormSubmit service.
